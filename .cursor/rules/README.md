# SkyTrack Backend Cursor Rules

This directory contains Cursor rules for the SkyTrack Backend project. These rules enforce consistent coding standards, security practices, and documentation requirements.

## Available Rules

- `skytrack-backend-standards.mcd`: Comprehensive development standards for authentication, security, logging, and documentation

## How Rules Work

Cursor automatically applies these rules when you work on files in the `src/` directory. The rules provide suggestions and enforce standards for:

- Authentication and authorization
- Security headers and protection
- Error handling and logging
- API response formats
- Documentation requirements
- Code organization
- Database operations
- Testing and validation

## Testing Rules

To verify rules are being applied:

1. Open a TypeScript/JavaScript file in the `src/` directory
2. Look for rule-based suggestions or warnings
3. Check if the agent follows the patterns defined in the rules

## Updating Rules

When updating rules:

1. Edit the appropriate `.mcd` file
2. Restart Cursor to apply changes
3. Test the updated rules on a sample file
